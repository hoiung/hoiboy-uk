# Dev-only dependencies for hook scripts + tests.
# CI installs via `pip install -r requirements-dev.txt`.
# Local contributors: `pip install -r requirements-dev.txt` to run the scripts
# or the tests directly. The two pre-commit hooks that need PyYAML
# (frontmatter-validator, check-wordcount) declare it via
# additional_dependencies, so pre-commit provisions it in their managed env
# even without this file installed.
pytest
pyyaml
piexif
# Pillow: the social-card generators measure text and composite images with it
# (scripts/social-cards/gen_card.py imports PIL at 4 sites, gen_agit_feature.py at
# module level). It was an undeclared local-only dependency until blog-priv#62 wired
# scripts/test_gen_card.py into CI for the first time -- the tests import gen_card,
# gen_card imports PIL, CI installs only this file, so the step failed on the merge
# commit with ModuleNotFoundError. It could not fail earlier: ci.yml triggers on
# `push: branches: [main]` and `pull_request` only, and a solo branch is neither.
pillow
# Playwright: scripts/check_cta_rendered.py drives headless Chromium to read the
# CTA button's COMPUTED style, which is the only way to test a cascade rather
# than model it. It was undeclared until the blog-priv#63 Stage 5 audit: the
# gate's one invocation path (scripts/pre-publish.sh) would hit its own
# `except ImportError` and exit 2 for anyone who set up exactly as documented.
# The browser binary is a separate one-time step and is NOT pip-installable:
#   playwright install chromium
# CI does not install either; the browser half runs in the pre-publish lane.
playwright
